# 放下

Let Go

人很小，背包很大，山壁很陡。背包里装着放不下的东西：奖杯、一封没寄出的信、戒指、一张旧照片。每一样都有重量，摆荡会更短、更难。走到歇脚处，可以永久放下眼前这一件。山顶看见什么，取决于你还带着什么。

**玩：** https://jeromeyu0007.github.io/Drop/

山、云、雪和光都在画布上当场算出来。没有图片，没有音频文件，也不需要外部库。打开仓库根目录的 `index.html` 就能玩。

## 操作

只有一个键：鼠标、触摸，或空格。

- **按住**：抓住岩点。身体开始摆，弧线慢慢变长。
- **松开**：顺着这一下飞出去。
- 弧线碰到红绳，就会抓住下一点。
- 失手会坠落。下坠时再按住，有时还能抓住更低的岩点。
- **歇脚处**：按住放下眼前这件东西，轻点则留下，继续向上。顺序是奖杯、信、戒指、照片。放下了就不会回来。
- 右上角 **重来** 立刻回到山脚，背包重新装满。坠落本身不会把已经放下的东西还你。

没有存档点。这台设备上到过的最高处会留下来。

左上角可以静音，也可以在中文和英文之间切换。风声、绳子和很少的几个音，都是用 WebAudio 临时算的。第一次按下去才会出声。
