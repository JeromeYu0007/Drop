Processing
----------
For the Poly Haven maps, Lanczos resampling and WebP compression use the
original source images without adding new patterns or fictional details.
No padding or extra unused images are included.
Original map MD5 values were verified against the official Poly Haven API.
16-bit roughness sources were scaled to 8-bit before encoding, preserving
roughness values. Color maps are sRGB; normal/roughness are linear data.
The original downloads remain outside the repository. manifest.json lists
exact source URLs, authors, input checksums, transformations, output sizes,
output SHA-256 values, dimensions and render color-space requirements.

Generated alpine background
---------------------------
alpine-panorama.webp is original project-specific AI-generated artwork made
with OpenAI image generation on 2026-11-14. It is not a photograph, does not
represent a named real location, and is not claimed as a CC0 source asset.
It depicts broad alpine massifs, snow gullies and valley clouds for the distant
background. Original image: 2172 by 724 pixels; only WebP encoding is applied.
The finite 3:1 matte is not a 360-degree equirectangular environment map.
OpenAI terms: https://openai.com/policies/terms-of-use/

All image files together: 4069620 bytes.
